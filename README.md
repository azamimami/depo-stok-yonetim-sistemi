
# 📦 DEPO & STOK YÖNETİM SİSTEMİ

Profesyonel ve kullanıcı dostu bir Depo ve Stok Yönetim Sistemi. PyQt5 ve Matplotlib kullanarak modern bir arayüz sunmaktadır.


# 🎯 Özellikler

# 📊 Dashboard
- **📦 Toplam Ürün Sayısı** - Sistemde kayıtlı ürün sayısı
- **💰 Toplam Stok Değeri** - Stokta olan tüm ürünlerin tutarı (TL)
- **🛒 Toplam Sipariş Tutarı** - Oluşturulan siparişlerin toplam tutarı (TL)
- Gerçek zamanlı güncelleme (0.5 saniyede bir)

# 📦 Ürün Yönetimi
- ➕ **Ürün Ekle** - Ürün adı, Stok miktarı ve Fiyat ile yeni ürün kaydı
- 📈 **Stok Arttır** - Seçili ürünün stok miktarını artırma
- 📉 **Stok Azalt** - Seçili ürünün stok miktarını azaltma
- 🗑️ **Ürün Sil** - Seçili ürünü sistemden silme
- 🔄 **Yenile** - Ürün listesini güncelleme
- Tüm ürünlerin detaylı tablo görünümü

# 🛒 Sipariş Yönetimi
- ➕ **Sipariş Oluştur** - Ürün seçimi ve adet ile sipariş oluşturma
- ✅ **Otomatik Stok Kontrolü** - Yetersiz stok varsa uyarı
- 💰 **Otomatik Fiyat Hesaplama** - Sipariş tutarı otomatik hesaplanır
- 📋 **Sipariş Geçmişi** - Oluşturulan tüm siparişlerin listesi
- Sipariş oluşturulduğunda stok otomatik güncellenir

# 📊 Grafikler & İstatistikler
- 📊 **Stok Dağılımı** - Ürünler bazında stok miktarları
- 💵 **Fiyat Dağılımı** - Ürünler bazında fiyat karşılaştırması
- 📈 **İstatistik Grafikleri** - Renkli bar grafikler
- Otomatik güncelleme
- Profesyonel görünüm
